# Optimize Reference

Detailed optimization command matrices are intentionally deferred.

Public optimization should stay conservative:

- require a measured baseline before improving candidates;
- preserve validation and heldout boundaries;
- start with local/dry-run interventions;
- require explicit approval for live calls, uploads, hosted jobs, or spend;
- promote narrowly with repeatable evidence and rollback criteria.

Add concrete commands here only when the public CLI implementation and artifact
paths are committed in this repo.
